# Flop · Póker con amigos

Texas Hold'em online para jugar con amigos. Gratis, sin registro y solo con fichas de juego (sin dinero real).

- Quien crea la mesa comparte el código o el enlace; los demás entran desde cualquier navegador o móvil.
- El navegador del anfitrión hace de crupier automático: reparte, controla turnos, ciegas, botes secundarios y decide quién gana. El anfitrión juega igual que los demás.
- Conexión directa entre navegadores (WebRTC vía PeerJS), sin servidor propio.
- Si el anfitrión recarga la página, la mesa se recupera y los jugadores se reconectan solos.

Sitio estático: `index.html`, `css/`, `js/`. Para probarlo en local basta con servir la carpeta con cualquier servidor estático.
